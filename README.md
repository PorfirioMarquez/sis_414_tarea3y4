# Proyecto Base Spring Boot 21 + PostgreSQL + Gradle

Este proyecto está configurado y listo para abrir en **IntelliJ IDEA**.

## Requisitos Previos
* **Java 21** (JDK 21 instalado y configurado en IntelliJ).
* **PostgreSQL** corriendo localmente con una base de datos creada (por defecto llamada `tu_base_datos`).

## Pasos para ejecutar:
1. Abre IntelliJ IDEA y selecciona **Open** indicando esta carpeta.
2. Espera a que Gradle descargue las dependencias automáticamente.
3. Modifica tus credenciales en `src/main/resources/application.properties`.
4. Ejecuta la clase principal `DemoApplication.java`.
